# Desktop demo in VS Code

Press F5 and choose **SmartShop ERP - Local Demo**. The Python debugger runs
Waitress in the Debug Console. Open http://127.0.0.1:8765. The temporary local
PostgreSQL demo cluster must be running first.

This demo uses the existing verified Python runtime and synthetic QA database
under the original Codex workspace. No real business records or private
configuration were copied to OneDrive/Desktop. The shop is visibly labeled
QA DEMO ONLY.

The launch configuration references local paths for this computer. Stop the
application with VS Code Stop Debugging. For an independent normal installation
and a fresh owner/shop, follow START_HERE.txt / SETUP_WINDOWS.md instead.
